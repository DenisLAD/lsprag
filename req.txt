Требования к плагину для улучшения.
1. При анализе методв необходимо пройтись в глубину и найти вызываемые методы, и тажке включить их в промпт
2. Если приложение на Spring, в инъекциях может использоваться интерфейс, для интерфейса нужно найти все классы реализации и сделать экстракцию вызвваемых методов основным методом для которого пишется тест (не включая стандартные java пакеты, и игнорируя классы для которых нет исходных кодов), глубину поиска необходимо настраивать в настройках
3. В коде метода для которого пишется тест, могут быть дополнительные вызовы для обогащения данных, нужно учитывать изменение входных параметров или трансформацию входных параметров
4. Акцент делается на качественную генерацию теста
5. Скорее всего нужно включать в промпт POJO и DTO (а также вложенные POJO и DTO), для понимания состава данных
6. Вложеность при анализе необходимо также задавать через конфигурацию
